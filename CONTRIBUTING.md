# 🤝 Contributing to CloudRedirectCN

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [huanyuejue/CloudRedirect](https://github.com/huanyuejue/CloudRedirect). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b master --single-branch --recursive https://github.com/NEVARLeVrai/CloudRedirectCN.git

## ✅ Verify your changes

Use a dedicated test directory and dummy save files to verify redirection. Describe the operating system and affected migration or cleanup behavior.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
